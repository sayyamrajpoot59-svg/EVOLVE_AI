# Simple Python Calculator

Ek aasan command-line calculator app jisme basic arithmetic operations hain: addition, subtraction, multiplication, aur division.

## Features
- **Add (+)**: Do numbers ko jodna
- **Subtract (-)**: Do numbers ko ghatana
- **Multiply (*)**: Do numbers ka gunanfal nikalna
- **Divide (/)**: Do numbers ko bhag karna (Division by zero protection ke sath)

## Kaise Run Karein

### App Chalayein:
```bash
python calculator.py
```

### Tests Run Karein:
```bash
python -m unittest test_calculator.py
```
